# ชุดข้อมูลใหม่จากผู้ใช้
[RECALL]
1|||Computer คืออะไร?|||อุปกรณ์อิเล็กทรอนิกส์ที่รับข้อมูล ประมวลผล จัดเก็บ และแสดงผลข้อมูล
2|||องค์ประกอบของระบบคอมพิวเตอร์มีอะไรบ้าง?|||Hardware, Software, Peopleware, Data และ Procedure
3|||Hardware คืออะไร?|||อุปกรณ์คอมพิวเตอร์ที่สามารถจับต้องได้
4|||Software คืออะไร?|||โปรแกรมหรือชุดคำสั่งที่ควบคุมการทำงานของคอมพิวเตอร์
5|||Peopleware คืออะไร?|||บุคลากรที่เกี่ยวข้องกับระบบคอมพิวเตอร์
6|||Data คืออะไร?|||ข้อมูลดิบที่ยังไม่ได้ผ่านการประมวลผล
7|||Information คืออะไร?|||ข้อมูลที่ผ่านการประมวลผลและมีความหมาย
8|||IPOS ย่อมาจากอะไร?|||Input, Process, Output, Storage
9|||Input Device คืออะไร?|||อุปกรณ์นำเข้าข้อมูล เช่น Keyboard และ Mouse
10|||Output Device คืออะไร?|||อุปกรณ์แสดงผล เช่น Monitor และ Printer
11|||CPU ย่อมาจากอะไร?|||Central Processing Unit
12|||CPU ทำหน้าที่อะไร?|||ประมวลผลคำสั่งและควบคุมการทำงานของคอมพิวเตอร์
13|||RAM ย่อมาจากอะไร?|||Random Access Memory
14|||RAM มีลักษณะสำคัญอย่างไร?|||เป็นหน่วยความจำชั่วคราว ข้อมูลหายเมื่อไม่มีไฟเลี้ยง
15|||ROM ย่อมาจากอะไร?|||Read Only Memory
16|||ROM มีลักษณะสำคัญอย่างไร?|||เป็นหน่วยความจำที่เก็บข้อมูลได้แม้ไม่มีไฟเลี้ยง
17|||Volatile Memory คืออะไร?|||หน่วยความจำที่สูญเสียข้อมูลเมื่อไม่มีไฟเลี้ยง
18|||Non-volatile Memory คืออะไร?|||หน่วยความจำที่เก็บข้อมูลได้แม้ไม่มีไฟเลี้ยง
19|||Bit คืออะไร?|||หน่วยข้อมูลพื้นฐานที่มีค่า 0 หรือ 1
20|||1 Byte เท่ากับกี่ Bit?|||8 Bit
21|||1 KiB เท่ากับกี่ Byte?|||1,024 Byte
22|||1 MiB เท่ากับกี่ KiB?|||1,024 KiB
23|||Binary เป็นระบบเลขฐานอะไร?|||ฐาน 2
24|||Octal เป็นระบบเลขฐานอะไร?|||ฐาน 8
25|||Decimal เป็นระบบเลขฐานอะไร?|||ฐาน 10
26|||Hexadecimal เป็นระบบเลขฐานอะไร?|||ฐาน 16
27|||ASCII คืออะไร?|||มาตรฐานการแทนรหัสอักขระ
28|||Unicode คืออะไร?|||มาตรฐานการแทนอักขระจากภาษาต่าง ๆ
29|||System Software คืออะไร?|||ซอฟต์แวร์ที่จัดการและควบคุมระบบคอมพิวเตอร์
30|||Application Software คืออะไร?|||โปรแกรมที่ใช้ทำงานตามความต้องการของผู้ใช้
31|||ALU ย่อมาจากอะไร?|||Arithmetic Logic Unit
32|||ALU ทำหน้าที่อะไร?|||คำนวณทางคณิตศาสตร์และตรรกศาสตร์
33|||CU ย่อมาจากอะไร?|||Control Unit
34|||CU ทำหน้าที่อะไร?|||ควบคุมและประสานการทำงานของหน่วยต่าง ๆ
35|||Register คืออะไร?|||หน่วยเก็บข้อมูลขนาดเล็กและความเร็วสูงภายใน CPU
36|||PC ย่อมาจากอะไร?|||Program Counter
37|||Program Counter ทำหน้าที่อะไร?|||เก็บตำแหน่งคำสั่งถัดไปที่จะประมวลผล
38|||IR ย่อมาจากอะไร?|||Instruction Register
39|||Instruction Register ทำหน้าที่อะไร?|||เก็บคำสั่งที่กำลังประมวลผล
40|||MAR ย่อมาจากอะไร?|||Memory Address Register
41|||MAR ทำหน้าที่อะไร?|||เก็บตำแหน่งหน่วยความจำที่ต้องการเข้าถึง
42|||MDR ย่อมาจากอะไร?|||Memory Data Register
43|||MDR ทำหน้าที่อะไร?|||เก็บข้อมูลที่รับจากหรือส่งไปยังหน่วยความจำ
44|||Accumulator ทำหน้าที่อะไร?|||เก็บผลลัพธ์หรือข้อมูลระหว่างการคำนวณ
45|||Stack Pointer ทำหน้าที่อะไร?|||เก็บตำแหน่งที่เกี่ยวข้องกับส่วนบนของ Stack
46|||Status Register ทำหน้าที่อะไร?|||เก็บสถานะผลการประมวลผล เช่น Zero และ Carry Flag
47|||Machine Cycle มีขั้นตอนพื้นฐานอะไรบ้าง?|||Fetch, Decode, Execute และ Store
48|||Fetch คืออะไร?|||การดึงคำสั่งจากหน่วยความจำ
49|||Decode คืออะไร?|||การถอดรหัสและตีความคำสั่ง
50|||Execute คืออะไร?|||การดำเนินการตามคำสั่ง
51|||Store คืออะไร?|||การบันทึกผลลัพธ์จากการประมวลผล
52|||Cache Memory มีหน้าที่อะไร?|||เก็บข้อมูลที่ใช้บ่อยเพื่อลดเวลาการเข้าถึงหน่วยความจำ
53|||Cache L1 มีลักษณะอย่างไร?|||โดยทั่วไปมีขนาดเล็กและเร็วที่สุดในระดับ Cache ของ CPU
54|||Clock Speed วัดด้วยหน่วยอะไร?|||Hertz เช่น MHz และ GHz
55|||CPU Core คืออะไร?|||หน่วยประมวลผลภายใน CPU
56|||Thread คืออะไร?|||หน่วยลำดับการดำเนินงานของโปรแกรม
57|||RISC ย่อมาจากอะไร?|||Reduced Instruction Set Computer
58|||CISC ย่อมาจากอะไร?|||Complex Instruction Set Computer
59|||Address Bus ทำหน้าที่อะไร?|||ส่งข้อมูลตำแหน่งหน่วยความจำหรืออุปกรณ์
60|||Data Bus ทำหน้าที่อะไร?|||ส่งข้อมูลระหว่างส่วนประกอบของระบบ
61|||Motherboard คืออะไร?|||แผงวงจรหลักที่เชื่อมต่ออุปกรณ์คอมพิวเตอร์
62|||PSU ทำหน้าที่อะไร?|||แปลงและจ่ายพลังงานไฟฟ้าให้ส่วนประกอบคอมพิวเตอร์
63|||GPU ทำหน้าที่อะไร?|||ประมวลผลกราฟิกและงานคำนวณแบบขนาน
64|||HDD จัดเก็บข้อมูลด้วยวิธีใด?|||ใช้แผ่นจานแม่เหล็ก
65|||SSD จัดเก็บข้อมูลด้วยวิธีใด?|||โดยทั่วไปใช้ NAND Flash Memory
66|||SSD มีข้อดีเหนือ HDD อย่างไร?|||เข้าถึงข้อมูลเร็วและไม่มีชิ้นส่วนกลไกเคลื่อนที่
67|||SATA คืออะไร?|||มาตรฐานเชื่อมต่ออุปกรณ์จัดเก็บข้อมูล
68|||NVMe คืออะไร?|||โปรโตคอลเข้าถึงหน่วยจัดเก็บข้อมูลแบบไม่ลบเลือนผ่าน PCIe เป็นหลัก
69|||BIOS คืออะไร?|||เฟิร์มแวร์สำหรับเริ่มต้นและตรวจสอบฮาร์ดแวร์
70|||UEFI คืออะไร?|||อินเทอร์เฟซเฟิร์มแวร์สมัยใหม่ที่ใช้แทน Legacy BIOS
71|||POST ย่อมาจากอะไร?|||Power-On Self-Test
72|||POST ทำหน้าที่อะไร?|||ตรวจสอบฮาร์ดแวร์เบื้องต้นก่อนเริ่มระบบปฏิบัติการ
73|||UPS ทำหน้าที่อะไร?|||จ่ายไฟสำรองชั่วคราวเมื่อไฟฟ้าหลักขัดข้อง
74|||Heat Sink ทำหน้าที่อะไร?|||ระบายความร้อนออกจากอุปกรณ์อิเล็กทรอนิกส์
75|||Thermal Paste ทำหน้าที่อะไร?|||ช่วยถ่ายเทความร้อนระหว่างชิปและชุดระบายความร้อน
76|||NIC ย่อมาจากอะไร?|||Network Interface Card
77|||NIC ทำหน้าที่อะไร?|||เชื่อมต่อคอมพิวเตอร์เข้ากับเครือข่าย
78|||RAID 0 คืออะไร?|||กระจายข้อมูลหลายไดรฟ์เพื่อเพิ่มประสิทธิภาพโดยไม่มีข้อมูลสำรองแบบ RAID
79|||RAID 1 คืออะไร?|||จัดเก็บข้อมูลซ้ำแบบ Mirroring
80|||RAID 5 คืออะไร?|||กระจายข้อมูลและ Parity โดยใช้ไดรฟ์อย่างน้อย 3 ลูก
81|||RAID 6 ทนต่อไดรฟ์เสียพร้อมกันได้กี่ลูก?|||2 ลูก
82|||RAID 10 คืออะไร?|||การผสม Mirroring และ Striping
83|||Firmware คืออะไร?|||ซอฟต์แวร์ระดับต่ำที่ควบคุมการทำงานของอุปกรณ์
84|||Device Driver คืออะไร?|||โปรแกรมที่ช่วยให้ระบบปฏิบัติการสื่อสารกับอุปกรณ์
85|||ECC RAM คืออะไร?|||หน่วยความจำที่ตรวจจับและแก้ไขข้อผิดพลาดบางประเภทได้
86|||Operating System คืออะไร?|||ซอฟต์แวร์ระบบที่จัดการทรัพยากรคอมพิวเตอร์
87|||OS ทำหน้าที่หลักอะไรบ้าง?|||จัดการ CPU หน่วยความจำ ไฟล์ อุปกรณ์ และกระบวนการ
88|||Kernel คืออะไร?|||ส่วนแกนกลางของระบบปฏิบัติการ
89|||Process คืออะไร?|||โปรแกรมที่กำลังดำเนินงาน
90|||Multitasking คืออะไร?|||การจัดการให้หลายงานดำเนินไปในช่วงเวลาเดียวกัน
91|||Multiprocessing คืออะไร?|||การใช้หลายหน่วยประมวลผลเพื่อทำงาน
92|||Context Switching คืออะไร?|||การบันทึกและสลับสถานะระหว่างงานประมวลผล
93|||Process Scheduling คืออะไร?|||การจัดลำดับการใช้ CPU ของ Process
94|||FCFS คืออะไร?|||First Come First Served
95|||SJF คืออะไร?|||Shortest Job First
96|||Round Robin คืออะไร?|||การจัดสรร CPU ให้แต่ละงานตามช่วงเวลาที่กำหนด
97|||Time Quantum คืออะไร?|||ระยะเวลาที่กำหนดให้ Process ใช้ CPU ต่อรอบ
98|||Deadlock คืออะไร?|||ภาวะที่กระบวนการรอทรัพยากรกันจนไม่สามารถดำเนินงานต่อได้
99|||Virtual Memory คืออะไร?|||กลไกจัดการพื้นที่หน่วยความจำเสมือนของระบบ
100|||Paging คืออะไร?|||การแบ่งหน่วยความจำออกเป็นหน่วยขนาดคงที่
101|||Page Fault คืออะไร?|||เหตุการณ์เมื่อโปรแกรมอ้างถึงหน้าหน่วยความจำที่ต้องให้ OS จัดการเพิ่มเติม
102|||File System คืออะไร?|||ระบบจัดระเบียบและจัดเก็บไฟล์
103|||NTFS นิยมใช้กับระบบใด?|||Windows
104|||ext4 นิยมใช้กับระบบใด?|||Linux
105|||GUI ย่อมาจากอะไร?|||Graphical User Interface
106|||CLI ย่อมาจากอะไร?|||Command Line Interface
107|||Shell คืออะไร?|||อินเทอร์เฟซที่ใช้สั่งงานระบบปฏิบัติการ
108|||Linux เป็นระบบปฏิบัติการประเภทใด?|||ระบบปฏิบัติการตระกูล Unix-like
109|||คำสั่ง ls ใน Linux ใช้ทำอะไร?|||แสดงรายการไฟล์และไดเรกทอรี
110|||คำสั่ง pwd ใช้ทำอะไร?|||แสดงตำแหน่งไดเรกทอรีปัจจุบัน
111|||Computer Network คืออะไร?|||การเชื่อมต่ออุปกรณ์เพื่อสื่อสารและใช้ทรัพยากรร่วมกัน
112|||Protocol คืออะไร?|||ข้อตกลงหรือกฎสำหรับการสื่อสารข้อมูล
113|||LAN ย่อมาจากอะไร?|||Local Area Network
114|||MAN ย่อมาจากอะไร?|||Metropolitan Area Network
115|||WAN ย่อมาจากอะไร?|||Wide Area Network
116|||PAN ย่อมาจากอะไร?|||Personal Area Network
117|||Topology คืออะไร?|||รูปแบบโครงสร้างการเชื่อมต่อเครือข่าย
118|||Star Topology คืออะไร?|||การเชื่อมต่ออุปกรณ์ผ่านอุปกรณ์ศูนย์กลาง
119|||Bus Topology คืออะไร?|||การเชื่อมต่อโดยใช้สื่อกลางหลักร่วมกัน
120|||Ring Topology คืออะไร?|||การเชื่อมต่ออุปกรณ์เป็นวงแหวน
121|||Mesh Topology คืออะไร?|||การเชื่อมต่ออุปกรณ์ผ่านหลายเส้นทาง
122|||Fiber Optic ส่งข้อมูลด้วยอะไร?|||แสง
123|||UTP ย่อมาจากอะไร?|||Unshielded Twisted Pair
124|||STP ในความหมายของสายสัญญาณคืออะไร?|||Shielded Twisted Pair
125|||Guided Media คืออะไร?|||สื่อกลางที่กำหนดเส้นทางสัญญาณ เช่น สายสัญญาณ
126|||Unguided Media คืออะไร?|||สื่อกลางไร้สาย เช่น คลื่นวิทยุและไมโครเวฟ
127|||Baseband คืออะไร?|||การส่งสัญญาณโดยใช้ช่องสัญญาณพื้นฐานของสื่อกลาง
128|||Broadband คืออะไร?|||การส่งข้อมูลที่สามารถแบ่งย่านความถี่เป็นหลายช่องสัญญาณ
129|||Hub ทำหน้าที่อะไร?|||ส่งต่อสัญญาณไปยังพอร์ตอื่นทั้งหมด
130|||Switch ทำหน้าที่อะไร?|||ส่งต่อ Ethernet Frame โดยอาศัย MAC Address
131|||Router ทำหน้าที่อะไร?|||เลือกเส้นทางและส่งต่อ Packet ระหว่างเครือข่าย
132|||Repeater ทำหน้าที่อะไร?|||ฟื้นฟูหรือส่งต่อสัญญาณเพื่อเพิ่มระยะทาง
133|||Gateway คืออะไร?|||จุดเชื่อมต่อระหว่างระบบหรือเครือข่าย
134|||Access Point ทำหน้าที่อะไร?|||เชื่อมต่ออุปกรณ์ไร้สายเข้ากับเครือข่าย
135|||Modem ทำหน้าที่อะไร?|||แปลงสัญญาณให้เหมาะสมกับระบบสื่อสาร
136|||MAC Address มีขนาดทั่วไปกี่ Bit?|||48 Bit
137|||IPv4 มีขนาดกี่ Bit?|||32 Bit
138|||IPv6 มีขนาดกี่ Bit?|||128 Bit
139|||DNS ทำหน้าที่อะไร?|||แปลงชื่อโดเมนเป็นข้อมูลที่เกี่ยวข้อง เช่น IP Address
140|||DHCP ทำหน้าที่อะไร?|||แจกจ่าย IP Address และค่าการตั้งค่าเครือข่ายอัตโนมัติ
141|||NAT ทำหน้าที่อะไร?|||แปลงหมายเลข IP Address ระหว่างเครือข่าย
142|||Subnet Mask ทำหน้าที่อะไร?|||ระบุส่วนเครือข่ายและส่วนโฮสต์ของ IPv4
143|||Default Gateway คืออะไร?|||จุดส่งต่อข้อมูลเมื่อปลายทางอยู่นอกเครือข่ายท้องถิ่น
144|||TCP มีจุดเด่นอะไร?|||ส่งข้อมูลแบบเชื่อมต่อและมีการควบคุมความน่าเชื่อถือ
