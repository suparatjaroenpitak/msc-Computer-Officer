ตอบ: ควบคุมผลกระทบระหว่าง Transaction ที่ทำงานพร้อมกัน

555. Durability ใน ACID คืออะไร?
ตอบ: ผลที่ยืนยันแล้วต้องคงอยู่แม้ระบบขัดข้องตามการรับประกันของระบบ

556. Database Replication คืออะไร?
ตอบ: การทำสำเนาข้อมูลระหว่างฐานข้อมูลหลายชุด

557. Database Sharding คืออะไร?
ตอบ: การแบ่งข้อมูลออกเป็นส่วน ๆ เพื่อกระจายการจัดเก็บ

558. OLTP ย่อมาจากอะไร?
ตอบ: Online Transaction Processing

559. OLAP ย่อมาจากอะไร?
ตอบ: Online Analytical Processing

560. NoSQL Database คืออะไร?
ตอบ: ฐานข้อมูลที่ใช้รูปแบบจัดเก็บข้อมูลนอกเหนือจากโมเดลเชิงสัมพันธ์แบบดั้งเดิมเป็นหลัก

561. Threat คืออะไร?

562. Vulnerability คืออะไร?
ตอบ: จุดอ่อนหรือช่องโหว่ของระบบ

563. Risk คืออะไร?
ตอบ: ความเสี่ยงที่พิจารณาจากโอกาสเกิดและผลกระทบ

564. Risk Assessment คืออะไร?
ตอบ: การประเมินความเสี่ยง

565. Risk Mitigation คืออะไร?
ตอบ: การดำเนินมาตรการเพื่อลดความเสี่ยง

566. Vulnerability Assessment คืออะไร?
ตอบ: การค้นหาและประเมินช่องโหว่ของระบบ

567. Penetration Testing คืออะไร?
ตอบ: การทดสอบความปลอดภัยโดยจำลองการโจมตีภายใต้ขอบเขตที่ได้รับอนุญาต

568. CVE ย่อมาจากอะไร?
ตอบ: Common Vulnerabilities and Exposures

569. CVSS ย่อมาจากอะไร?
ตอบ: Common Vulnerability Scoring System

570. ISO/IEC 27001 เกี่ยวข้องกับอะไร?
ตอบ: ระบบบริหารจัดการความมั่นคงปลอดภัยสารสนเทศ

571. ISMS ย่อมาจากอะไร?
ตอบ: Information Security Management System

572. NIST Cybersecurity Framework ใช้เพื่ออะไร?
ตอบ: เป็นกรอบแนวทางจัดการความเสี่ยงด้านความมั่นคงปลอดภัยไซเบอร์

573. DMZ ในระบบเครือข่ายคืออะไร?
ตอบ: เขตเครือข่ายแยกสำหรับบริการที่ต้องเปิดให้เข้าถึงจากภายนอก

574. Network Segmentation คืออะไร?
ตอบ: การแบ่งเครือข่ายเป็นส่วนย่อยเพื่อควบคุมการเข้าถึงและลดความเสี่ยง

575. WAF ย่อมาจากอะไร?
ตอบ: Web Application Firewall

576. WAF ใช้ป้องกันอะไร?
ตอบ: ภัยคุกคามที่มุ่งโจมตี Web Application ผ่าน HTTP หรือ HTTPS

577. EDR ย่อมาจากอะไร?
ตอบ: Endpoint Detection and Response

578. DLP ย่อมาจากอะไร?
ตอบ: Data Loss Prevention

579. Salt ใน Password Hashing คืออะไร?
ตอบ: ค่าที่เพิ่มให้ข้อมูลก่อน Hash เพื่อลดประโยชน์ของการโจมตีด้วยตาราง Hash ที่คำนวณไว้ล่วงหน้า

580. TLS ย่อมาจากอะไร?
ตอบ: Transport Layer Security

581. PKI ย่อมาจากอะไร?
ตอบ: Public Key Infrastructure

582. CA ในระบบ PKI คืออะไร?
ตอบ: Certificate Authority

583. Brute Force Attack คืออะไร?
ตอบ: การพยายามเดาค่าหรือรหัสผ่านจำนวนมาก

584. Dictionary Attack คืออะไร?
ตอบ: การเดารหัสผ่านจากรายการคำหรือรหัสที่คาดว่าจะถูกใช้

585. Credential Stuffing คืออะไร?
ตอบ: การนำข้อมูลบัญชีที่รั่วไหลไปทดลองเข้าสู่ระบบอื่น

586. Man-in-the-Middle Attack คืออะไร?
ตอบ: การแทรกตัวระหว่างคู่สื่อสารเพื่อดักรับหรือเปลี่ยนแปลงข้อมูล

587. Honeypot คืออะไร?
ตอบ: ระบบล่อเพื่อสังเกตและศึกษากิจกรรมที่น่าสงสัย

588. Security Hardening คืออะไร?
ตอบ: การลดช่องทางโจมตีและปรับการตั้งค่าระบบให้ปลอดภัยขึ้น

589. Defense in Depth คืออะไร?
ตอบ: การใช้มาตรการรักษาความปลอดภัยหลายชั้น

590. Non-repudiation คืออะไร?
ตอบ: คุณสมบัติที่ช่วยสร้างหลักฐานเพื่อป้องกันการปฏิเสธการกระทำภายหลัง
