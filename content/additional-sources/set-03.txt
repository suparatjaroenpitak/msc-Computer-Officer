661. Client-Server Architecture คืออะไร?
ตอบ: สถาปัตยกรรมที่ Client ร้องขอบริการและ Server ตอบสนองคำขอ

662. Three-tier Architecture ประกอบด้วยอะไร?
ตอบ: Presentation Tier, Application Tier และ Data Tier

663. Presentation Tier ทำหน้าที่อะไร?
ตอบ: แสดงผลและรับข้อมูลจากผู้ใช้งาน

664. Application Tier ทำหน้าที่อะไร?
ตอบ: ประมวลผลกฎทางธุรกิจและการทำงานของระบบ

665. Data Tier ทำหน้าที่อะไร?
ตอบ: จัดเก็บและจัดการข้อมูล

666. MVC ย่อมาจากอะไร?
ตอบ: Model View Controller

667. Model ใน MVC ทำหน้าที่อะไร?
ตอบ: จัดการข้อมูลและตรรกะที่เกี่ยวข้องกับข้อมูลหรือโดเมน

668. View ใน MVC ทำหน้าที่อะไร?
ตอบ: แสดงผลข้อมูลให้ผู้ใช้งาน

669. Controller ใน MVC ทำหน้าที่อะไร?
ตอบ: รับคำขอและประสานการทำงานระหว่างส่วนต่าง ๆ

670. Responsive Web Design คืออะไร?
ตอบ: การออกแบบเว็บไซต์ให้ปรับการแสดงผลตามขนาดหน้าจอ

671. Cookie คืออะไร?
ตอบ: ข้อมูลที่เว็บไซต์กำหนดให้เบราว์เซอร์จัดเก็บและส่งกลับตามเงื่อนไข

672. Session Management คืออะไร?
ตอบ: การจัดการสถานะการใช้งานและตัวตนของผู้ใช้ระหว่างหลายคำขอ

673. Input Validation คืออะไร?
ตอบ: การตรวจสอบข้อมูลนำเข้าให้ตรงตามรูปแบบและเงื่อนไขที่กำหนด

674. Output Encoding คืออะไร?
ตอบ: การแปลงข้อมูลก่อนแสดงผลตามบริบทเพื่อป้องกันการตีความที่ไม่เหมาะสม

675. CRUD ย่อมาจากอะไร?
ตอบ: Create, Read, Update, Delete

676. HTTP PUT ใช้ทำอะไร?
ตอบ: สร้างหรือแทนที่สถานะของทรัพยากรตาม URI ที่กำหนด

677. HTTP PATCH ใช้ทำอะไร?
ตอบ: ปรับปรุงทรัพยากรบางส่วน

678. HTTP DELETE ใช้ทำอะไร?
ตอบ: ขอให้ลบความสัมพันธ์ของทรัพยากรกับ URI ที่กำหนด

679. HTTP 201 หมายถึงอะไร?
ตอบ: Created หรือสร้างทรัพยากรสำเร็จ

680. HTTP 204 หมายถึงอะไร?
ตอบ: No Content หรือคำขอสำเร็จโดยไม่มีเนื้อหาตอบกลับ

681. HTTP 400 หมายถึงอะไร?
ตอบ: Bad Request

682. HTTP 401 หมายถึงอะไร?
ตอบ: Unauthorized หรือคำขอไม่มีข้อมูลยืนยันตัวตนที่ใช้ได้

683. HTTP 403 หมายถึงอะไร?
ตอบ: Forbidden หรือ Server ปฏิเสธการดำเนินการตามคำขอ

684. HTTP 405 หมายถึงอะไร?
ตอบ: Method Not Allowed

685. HTTP 429 หมายถึงอะไร?
ตอบ: Too Many Requests

686. HTTP 502 หมายถึงอะไร?
ตอบ: Bad Gateway

687. HTTP 503 หมายถึงอะไร?
ตอบ: Service Unavailable

688. CORS ย่อมาจากอะไร?
ตอบ: Cross-Origin Resource Sharing

689. Middleware คืออะไร?
ตอบ: ส่วนประกอบที่ประมวลผล Request หรือ Response ระหว่างขั้นตอนการทำงาน

690. Rate Limiting คืออะไร?
ตอบ: การจำกัดจำนวนคำขอภายในช่วงเวลาที่กำหนด

691. Compiler คืออะไร?

692. Interpreter คืออะไร?
ตอบ: โปรแกรมที่ประมวลผลคำสั่งของภาษาโปรแกรมโดยตรงหรือผ่านรูปแบบกลาง

693. Source Code คืออะไร?

694. Machine Code คืออะไร?
ตอบ: คำสั่งในรูปแบบที่หน่วยประมวลผลสามารถดำเนินการได้

695. Syntax Error คืออะไร?
ตอบ: ข้อผิดพลาดจากการเขียนคำสั่งไม่ตรงตามไวยากรณ์ของภาษา

696. Runtime Error คืออะไร?
ตอบ: ข้อผิดพลาดที่เกิดขึ้นระหว่างโปรแกรมทำงาน

697. Logic Error คืออะไร?
ตอบ: ข้อผิดพลาดที่ทำให้ผลลัพธ์ไม่ตรงตามที่ต้องการแม้โปรแกรมทำงานได้

698. Debugging คืออะไร?
ตอบ: กระบวนการค้นหาและแก้ไขข้อผิดพลาดของโปรแกรม

699. Breakpoint คืออะไร?
ตอบ: จุดที่กำหนดให้โปรแกรมหยุดชั่วคราวเพื่อใช้ตรวจสอบการทำงาน

700. Exception คืออะไร?
ตอบ: เหตุการณ์ผิดปกติระหว่างการทำงานที่สามารถจัดการผ่านกลไกของภาษาโปรแกรม

701. try-catch ใช้ทำอะไร?
ตอบ: ตรวจจับและจัดการ Exception

702. finally ใช้ทำอะไร?
ตอบ: กำหนดคำสั่งที่โดยทั่วไปจะทำงานหลังจบ try หรือ catch

703. Recursion คืออะไร?
ตอบ: การที่ฟังก์ชันเรียกตัวเองโดยตรงหรือโดยอ้อม

704. Base Case คืออะไร?
ตอบ: เงื่อนไขหยุดการเรียกซ้ำของ Recursion

705. Infinite Loop คืออะไร?
ตอบ: การวนรอบที่ไม่สิ้นสุด

706. Linked List คืออะไร?
ตอบ: โครงสร้างข้อมูลที่ประกอบด้วย Node ซึ่งเชื่อมโยงกัน

707. Singly Linked List คืออะไร?
ตอบ: Linked List ที่แต่ละ Node เชื่อมไปยัง Node ถัดไป

708. Doubly Linked List คืออะไร?
ตอบ: Linked List ที่แต่ละ Node เชื่อมไปยัง Node ก่อนหน้าและถัดไป

719. Bubble Sort คืออะไร?

725. O(1) หมายถึงอะไร?
ตอบ: ความซับซ้อนที่ไม่เพิ่มตามขนาดข้อมูล

726. O(n) หมายถึงอะไร?
ตอบ: ความซับซ้อนที่เพิ่มตามขนาดข้อมูลแบบเชิงเส้น

727. O(log n) หมายถึงอะไร?
ตอบ: ความซับซ้อนที่เพิ่มแบบลอการิทึม

728. O(n²) หมายถึงอะไร?
ตอบ: ความซับซ้อนที่มีขอบเขตบนเพิ่มตามกำลังสองของขนาดข้อมูล

729. Time Complexity คืออะไร?
ตอบ: การวิเคราะห์การเติบโตของเวลาที่ Algorithm ใช้

730. Space Complexity คืออะไร?
ตอบ: การวิเคราะห์การเติบโตของพื้นที่หน่วยความจำที่ Algorithm ใช้

746. Window Function คืออะไร?
ตอบ: ฟังก์ชันที่คำนวณข้อมูลจากกลุ่มแถวที่เกี่ยวข้องโดยไม่รวมแถวให้เหลือแถวเดียว

747. ROW_NUMBER() ใช้ทำอะไร?
ตอบ: กำหนดหมายเลขลำดับให้แต่ละแถว

748. RANK() ใช้ทำอะไร?
ตอบ: จัดอันดับข้อมูลโดยค่าที่เท่ากันมีอันดับเดียวกันและอาจข้ามอันดับถัดไป

749. DENSE_RANK() แตกต่างจาก RANK() อย่างไร?

754. Database Lock คืออะไร?

755. Dirty Read คืออะไร?
ตอบ: การอ่านข้อมูลที่ Transaction อื่นยังไม่ได้ COMMIT

756. Non-repeatable Read คืออะไร?
ตอบ: การอ่านแถวเดิมซ้ำแล้วได้ค่าต่างกันเนื่องจาก Transaction อื่นเปลี่ยนข้อมูล

757. Phantom Read คืออะไร?
ตอบ: การอ่านด้วยเงื่อนไขเดิมแล้วพบชุดแถวเปลี่ยนไปจากการทำงานของ Transaction อื่น

758. Read Committed คืออะไร?
ตอบ: Isolation Level ที่ไม่อนุญาตให้อ่านข้อมูลที่ยังไม่ได้ COMMIT

759. Serializable คืออะไร?
ตอบ: Isolation Level ที่ให้ผลการทำงานเสมือน Transaction ดำเนินตามลำดับ

760. Connection Pool คืออะไร?
ตอบ: กลไกจัดเก็บและนำการเชื่อมต่อฐานข้อมูลกลับมาใช้ซ้ำ

761. Edge Computing คืออะไร?
ตอบ: การประมวลผลข้อมูลใกล้แหล่งกำเนิดข้อมูลเพื่อลดความล่าช้า

765. Elasticity คืออะไร?

ตอบ: การเพิ่มทรัพยากรให้เครื่องหรือ Instance เดิม

768. Cloud Region คืออะไร?
ตอบ: พื้นที่ทางภูมิศาสตร์ที่ผู้ให้บริการ Cloud จัดตั้งทรัพยากร

769. Availability Zone คืออะไร?
ตอบ: เขตโครงสร้างพื้นฐานที่แยกความขัดข้องออกจากเขตอื่นภายใน Region

770. High Availability คืออะไร?
ตอบ: การออกแบบระบบให้พร้อมใช้งานในระดับสูงและลด Downtime

771. Fault Tolerance คืออะไร?
ตอบ: ความสามารถของระบบในการทำงานต่อเมื่อส่วนประกอบบางส่วนขัดข้อง

772. Failover คืออะไร?
ตอบ: การสลับการทำงานไปยังระบบสำรองเมื่อระบบหลักขัดข้อง

773. Single Point of Failure คืออะไร?
ตอบ: จุดที่หากขัดข้องเพียงจุดเดียวจะทำให้ระบบหรือบริการหยุดทำงาน

774. Object Storage คืออะไร?
ตอบ: ระบบจัดเก็บข้อมูลในรูปแบบ Object พร้อมข้อมูลกำกับ

775. Block Storage คืออะไร?
ตอบ: ระบบจัดเก็บข้อมูลในรูปแบบ Block ที่สามารถนำไปใช้เป็น Volume ได้

776. File Storage คืออะไร?
ตอบ: ระบบจัดเก็บข้อมูลในรูปแบบไฟล์และไดเรกทอรี

777. Snapshot คืออะไร?
ตอบ: สำเนาสถานะข้อมูลหรือระบบ ณ ช่วงเวลาหนึ่ง

778. CDN ย่อมาจากอะไร?
ตอบ: Content Delivery Network

779. CDN มีประโยชน์อย่างไร?
ตอบ: กระจายเนื้อหาไปยังจุดให้บริการที่เหมาะสมเพื่อลดความล่าช้าและภาระ Server

780. Infrastructure as Code คืออะไร?
ตอบ: การกำหนดและจัดการโครงสร้างพื้นฐานผ่าน Code หรือไฟล์ Configuration

781. Shared Responsibility Model คืออะไร?
ตอบ: รูปแบบแบ่งความรับผิดชอบด้านความปลอดภัยระหว่างผู้ให้บริการ Cloud กับลูกค้า

782. IAM ย่อมาจากอะไร?
ตอบ: Identity and Access Management

783. Multi-tenancy คืออะไร?
ตอบ: การให้ผู้ใช้หรือองค์กรหลายรายใช้ระบบหรือทรัพยากรร่วมกันโดยมีการแยกข้อมูลตามที่ออกแบบ

ตอบ: การย้ายระบบ แอปพลิเคชัน หรือข้อมูลเข้าสู่สภาพแวดล้อม Cloud

785. Vendor Lock-in คืออะไร?
